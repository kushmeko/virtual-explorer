# Как выложить программу на GitHub

Программировать и ставить ничего не нужно - всё делается в браузере. Установщик собирает
сам GitHub на своём компьютере с Windows, бесплатно. Займёт минут 15, большая часть - ожидание.

## Один раз: создать репозиторий

1. Зарегистрируйся на **github.com** (если ещё нет аккаунта).
2. Справа вверху **«+» → «New repository»**.
3. **Repository name:** например `virtual-explorer` (латиницей, без пробелов).
4. Выбери **Public** (открытый). Так сборки бесплатны без ограничений, люди смогут скачать
   программу, а сама программа - узнавать о новых версиях.
5. Галочки «Add a README» и остальные **не ставь**. Нажми **«Create repository»**.

## Загрузить файлы

1. На странице нового репозитория нажми ссылку **«uploading an existing file»**.
2. Открой распакованную папку `virtual-explorer` на компьютере, выдели **всё, что внутри**
   (Ctrl+A) и перетащи в окно браузера. Важно: перетаскивать **содержимое папки**, а не саму
   папку - чтобы `main.py`, `app`, `packaging` и `.github` оказались на верхнем уровне.
   - Если папку `.github` не видно: в Проводнике «Вид → Показать → Скрытые элементы».
3. Подожди, пока загрузятся все файлы, внизу нажми **«Commit changes»**.
4. Проверь: на главной странице репозитория должна быть папка **`.github`**. Если её нет -
   повтори загрузку только для неё.

После загрузки GitHub сразу начнёт пробную сборку (вкладка **Actions**, жёлтый кружок).
Это проверка, релиза пока не будет.

## Выпустить версию (каждый раз, когда хочешь выложить обновление)

1. Вкладка **Actions** → слева **«Сборка Windows»** → справа кнопка **«Run workflow»**.
2. Впиши версию, например `1.5.0`, и нажми зелёную **«Run workflow»**.
3. Подожди ~10-15 минут. Зелёная галочка ✓ - готово, красный крестик ✗ - что-то сломалось.
4. На главной странице репозитория справа появится **Releases** → там
   **VirtualExplorer-1.5.0-Setup.exe** (установщик) и **…-portable.zip** (без установки).

Ссылку на страницу Releases можно давать кому угодно - это и есть «скачать программу».
Каждая следующая версия должна иметь номер больше: `1.5.1`, `1.6.0`… Установленная программа
сама заметит новый релиз и предложит обновиться.

## Если сборка упала (красный крестик)

Открой упавший запуск → шаг с крестиком → скопируй текст ошибки и пришли его Claude вместе
с версией программы. Чаще всего это видно на шаге «Самопроверка собранной программы».

## Обновить файлы в репозитории

Для новой версии кода: снова **«Add file → Upload files»** и перетащи содержимое новой папки -
GitHub заменит старые файлы. Потом - «Выпустить версию».

Удобнее (по желанию): программа **GitHub Desktop** (desktop.github.com) - там папка на компьютере
связана с репозиторием, и обновления отправляются кнопкой «Push».

## Почему Windows предупреждает при установке

У программы нет платной цифровой подписи (стоит от ~$200 в год), поэтому фильтр SmartScreen
показывает «Windows защитил ваш компьютер». Нужно нажать «Подробнее» → «Выполнить в любом
случае». Чем больше людей скачивают программу, тем реже появляется предупреждение.
