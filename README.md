# Виртуальный проводник

Приложение для Windows: файлы остаются на диске, а организуются тегами
и коллекциями - в стиле Steam. Стек: Python + PySide6 (Qt) + SQLite.

## Установка
1. Открой страницу **Releases** этого репозитория (справа на главной странице) и скачай
   **VirtualExplorer-…-Setup.exe**.
2. Запусти. Если Windows покажет «Windows защитил ваш компьютер» - «Подробнее» →
   «Выполнить в любом случае» (так бывает у программ без платной цифровой подписи).
3. «Далее» → «Установить». Права администратора не нужны. Нужна Windows 10/11, 64-бит.

Новая версия ставится поверх старой - теги и настройки сохраняются. Программа сама
раз в день проверяет, не вышла ли новая версия (можно выключить в настройках).
Без установки: **VirtualExplorer-…-portable.zip** - распаковать и запустить `VirtualExplorer.exe`.

## Запуск из исходников (для разработки)
    pip install -r requirements.txt
    python main.py
    python main.py --safe     # безопасный режим: без проверки файлов

Данные программы теперь лежат в `%LOCALAPPDATA%\VirtualExplorer\` (база, кэш обложек,
резервные копии) - рядом с твоими файлами программа ничего не создаёт.
Старая база из папки запуска (v0.3-v0.6) при первом запуске сама скопируется туда;
старый файл остаётся как ещё одна копия. Другая папка данных: переменная `VE_DATA_DIR`.

## Сборка
Программу собирает GitHub (файл `.github/workflows/build.yml`) на своём компьютере с Windows:
PyInstaller делает `VirtualExplorer.exe`, Inno Setup - установщик. После сборки GitHub сам
запускает программу (`--self-test`), ставит её установщиком, запускает ещё раз и удаляет -
сломанная сборка не попадёт в релиз. Как выложить новую версию - см. `КАК_ВЫЛОЖИТЬ_НА_GITHUB.md`.

Собрать у себя на Windows:

    pip install -r packaging/requirements-build.txt
    python packaging/stamp_version.py "" 1.5.0
    pyinstaller packaging/virtual_explorer.spec --noconfirm
    "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /DAppVersion=1.5.0 packaging\installer.iss

## Теги как в Steam (v0.4)
- **Фильтр с исключением.** Клик по плашке: не важно → ✓ нужен → ✕ исключить → не важно.
  ПКМ по плашке - меню: «только этот тег», цвет, группа, переименовать, удалить.
- **И / ИЛИ.** «Нужны все ✓ теги» или «нужен любой ✓ тег». Исключённые ✕ убираются всегда.
- **Живые счётчики.** Число на плашке - сколько файлов с этим тегом среди найденных сейчас;
  пустые плашки прячутся, популярные - первыми, «Ещё N ▾» раскрывает остальные, есть поиск тега.
- **Группы тегов** (как «Жанр»/«Тематика»): плашки стоят по группам. Авто-теги - в «Тип файла».
- **Окно «Метки…» (Ctrl+T)** - поиск, популярные метки галочками, создание новой метки.
  Работает сразу для нескольких файлов: ◪ - тег есть у части файлов.
- **Мультивыбор** в сетке и списке (Ctrl/Shift + клик): теги, избранное и коллекции - сразу всем.
  ПКМ → «Быстрый тег» - популярные теги одним кликом.
- **Теги у файла справа:** клик по названию - показать все файлы с этим тегом, ✕ - снять.
- **Менеджер тегов:** таблица всех тегов - переименование, цвет, группа, объединение, удаление.
  При удалении/слиянии правила динамических коллекций правятся сами.
- **«Без тегов»** в сайдбаре - файлы, к которым не подобрался вообще ни один тег,
  даже авто-тег по типу (неизвестные и непонятные файлы).
- **«Без персонализированных тегов»** - файлы без твоих тегов (авто-теги не считаются).
- **«Без авто-тегов»** - файлы, к которым не подобрался авто-тег по типу, даже если
  у них уже есть твои теги (неизвестный файл с твоим тегом уходит из «Без тегов» сюда).
- **Динамические коллекции:** теги ✓/✕ и режим И/ИЛИ; текущий фильтр подставляется в правила сам.

## Перетаскивание (v0.5)
Выдели файлы в сетке или списке и тащи мышкой в сайдбар:
- на **коллекцию** - файлы попадут в неё (пункт подсвечивается, внизу подсказка);
- на **★ Избранное** - в избранное;
- на заголовок **КОЛЛЕКЦИИ** - создастся новая коллекция из этих файлов;
- на динамическую коллекцию - нельзя: она наполняется сама по правилам.
Под курсором - обложка и число файлов. Тащатся только записи из базы:
в проводник Windows их не бросить, файлы на диске не сдвинутся.

## Файлы на диске (v0.6)
Программа следит за **папками библиотеки** (кнопка «📁 Папки библиотеки», как в Steam).
Папка, добавленная через «Добавить папку», попадает туда сама.
- **Переместил или переименовал файл** внутри папок библиотеки - запись переезжает за ним,
  теги, коллекции и ★ остаются. Узнаём по «номеру» файла на диске (NTFS), а если его нет
  (перенос на другой диск) - по имени+размеру или размеру+времени изменения.
  Если вариантов несколько - не гадаем, файл добавится как новый.
- **Удалил файл / вынул флешку** - запись не удаляется, а становится «⚠ Потерянной»:
  серая обложка, пункт «⚠ Потерянные» в сайдбаре (появляется, только когда такие есть).
  Вставил флешку обратно - всё вернулось само.
- **Положил новый файл** в папку библиотеки - он появится сам (с авто-тегом).
- **Потерянный файл** можно «🔍 Найти вручную…» (показать, где он теперь - теги сохранятся)
  или «Убрать из библиотеки» (с диска ничего не удаляется).
- Служебные файлы не добавляются: desktop.ini, Thumbs.db, ~$временные Office,
  недокачанные .part/.crdownload/.tmp, а также база и кэш обложек самой программы.

Когда проверяется: сразу при запуске (в фоне), при каждом изменении в папках
(через 1,5 с тишины, только изменившиеся папки), раз в 5 минут полностью
и по кнопке «🔄 Проверить файлы». Итог пишется в строку состояния.

## v1.8 - главное отличие видно сразу

Главное отличие программы от аналогов (проверено на TagSpaces Lite): если файл переименовать или
переместить в Проводнике, теги не теряются. Раньше программа находила такой файл молча.

- **Уведомление над файлами:** «Файл отчёт.docx переименован в отчёт_итог.docx - программа нашла
  его сама. Теги, коллекции и оценки сохранены». Если файлов несколько - их число и первые имена.
  Уведомление само скрывается через 20 секунд, кнопка ✕ - сразу.

## v1.6 - по отзыву первого тестировщика

Отзыв: «интерфейс не понравился, нет возможности менять масштаб и всё очень лагает».

- **Масштаб интерфейса:** «⚙ Настройки → Внешний вид → Масштаб интерфейса», от 80% до 175%.
  Увеличивает всё сразу - текст, кнопки, значки. Программа предлагает перезапуститься.
- **Меньше лагов:**
  - поиск цветов картинок (для поиска по цвету) читал каждую картинку по одному пикселю - 1024
    вызова на картинку, сотни картинок подряд, и окно в это время тормозило. Теперь картинка
    читается целиком за один раз, между картинками - короткие паузы для окна;
  - все фоновые задачи работают с пониженным приоритетом - окно важнее;
  - превью грузятся в 2 потока вместо 4, чтобы не забирать весь процессор на слабых ноутбуках.

## v1.5 - программа, которую можно установить

- **Установщик** для Windows: меню «Пуск», значок на рабочем столе (по желанию), удаление через
  «Параметры → Приложения». Ставится без прав администратора. При удалении спрашивает,
  удалить ли и библиотеку тегов (по умолчанию - нет).
- **Переносная версия** (zip) - запускается без установки.
- **Автоматическая сборка на GitHub:** одна кнопка - и через ~10 минут на странице Releases
  готовый установщик. Перед релизом GitHub сам проверяет, что программа запускается.
- **Проверка обновлений:** раз в день программа спрашивает GitHub, нет ли новой версии, и
  предлагает скачать («Скачать / Пропустить эту версию / Позже»). В «⚙ Настройки → О программе»
  - кнопка «Проверить сейчас» и выключатель.
- **Журнал ошибок** `errors.log`: если что-то сломалось, программа покажет окно с ошибкой,
  а не закроется молча; аварийные падения тоже записываются. Открыть - «⚙ Настройки →
  О программе → Журнал ошибок».
- **Одна копия программы:** повторный запуск показывает уже открытое окно (раньше вторая копия
  ошибочно предлагала безопасный режим).
- **Значок программы.**

## v1.4 - исправление ошибок

### Сетка больше не вылетает на тысячах картинок
Раньше при переключении на «плитки» каждая плитка сразу получала полноразмерную обложку,
а превью грузились для всех файлов разом: на 2000+ картинок это сотни мегабайт - окно
зависало и программа вылетала. Теперь:
- невидимые плитки показывают **одну общую заглушку** на тип файла;
- настоящие обложки рисуются **только для видимых плиток** (и ещё экран сверху и снизу)
  и сразу **в размере плитки**, а не 320×240;
- превью грузятся только для видимых плиток, при прокрутке очередь сбрасывается;
- у кэшей обложек есть **пределы памяти**, дальние плитки возвращаются к заглушке.

### Шрифт
- Убран шрифт «Как в Steam». Остались **«Системный»**, новый **Inter** - аккуратный
  современный шрифт с кириллицей, бесплатный (лицензия OFL), **вложен в программу**
  (папка `app/fonts`), - и «Другой…» (любой установленный).
- У кого был выбран «Как в Steam», автоматически включится «Системный».

### Мелочи
- Окно настроек: при первом открытии строки больше не налезают друг на друга.
- Везде длинное тире заменено на обычный дефис «-».

## v1.3 - настройки, темы, обучение

### Новое окно настроек
- Разворачивается на весь экран и тянется за край, каждая страница **прокручивается**.
- Настройки разложены по **карточкам**: название и пояснение слева, переключатель справа.
- Внешний вид меняется **сразу** (предпросмотр); «Отмена» возвращает как было.
- **Горячие клавиши починены:** строки выше, сочетания видны целиком; есть поиск по действиям.

### Темы
- **Тёмная (как в Steam)** - заготовка (по умолчанию), **Тёмная** - обычная нейтральная,
  **Светлая**, **Как в системе**.
- **Своя тема:** любой из 11 цветов (фон, панели, карточки, поля, текст, второстепенный текст,
  акцент, выделение, текст на выделении, наведение, рамки). Готовая тема становится основой.
- **Сохранить как тему** под своим именем - появится в списке со ★; сохранённую можно
  править и удалить. Отдельной настройки «акцентный цвет» больше нет - это цвет своей темы.
- **Текст:** шрифт, размер, свой цвет (с v1.4 шрифт «Как в Steam» заменён на вшитый Inter).

### Без дублей
- У каждой функции одно место: инструкция, горячие клавиши и папка данных - в настройках;
  менеджер тегов и проверка файлов - на верхней панели; правила, дубликаты, статистика,
  резервные копии, экспорт/импорт - в «☰ Ещё».
- **«Без тегов», «Без своих тегов», «Без авто-тегов»** больше не отдельные разделы:
  **ПКМ по «Все файлы», «★ Избранное» или «🕘 Недавние»** → выбрать один фильтр. Он работает
  во всех трёх разделах; над файлами видна кнопка «Показаны: … ✕», чтобы снять его.

### Обучение
- При первом запуске - **обучение со стрелками**: экран затемняется, нужная кнопка подсвечена,
  стрелка ведёт к ней от подсказки (11 шагов; Enter - дальше, Esc - закрыть).
- Пройти заново или открыть текстовую инструкцию - «⚙ Настройки → Инструкция» (или F1).

## v1.2 - удобство и кастомизация

### Интерфейс как в Steam
- **Компактная верхняя панель:** ◀ ▶ · ↶ ↷ · **＋ Добавить ▾** (папку, коллекцию, динамическую) ·
  🗂 Теги · 🔄 - справа ☰ Ещё, ⚙ Настройки и ▤ панель деталей.
- **Сетка/список - одна кнопка-иконка** рядом с сортировкой; **ползунок размера обложек**
  виден только в режиме «Сетка».
- **Боковая панель как в Steam:** название слева, счётчик серым справа, длинные названия
  аккуратно обрезаются с подсказкой.
- Правая панель без пустого места, когда файл не выбран; её можно спрятать (▤ или Ctrl+P).
- **«☰ Ещё» по разделам:** Теги · Библиотека · Данные · Программа.

### ⚙ Настройки (Ctrl+,)
- **Внешний вид:** тема (тёмная / светлая / системная), **акцентный цвет** (9 готовых или свой),
  размер интерфейса 85-150 %, плотность списков, язык (пока русский), сколько значков тегов
  на обложке (0-5), звёзды и цветная полоска на обложках, панель деталей.
- **Библиотека:** сколько файлов показывать за раз, что открывать при запуске
  (последний раздел или «Все файлы»), слежение за папками, фоновый поиск дубликатов и цветов,
  порог «много файлов» при добавлении, подтверждение «Убрать из библиотеки».
- **Горячие клавиши:** все можно поменять (кликни и нажми сочетание), ↺ - вернуть одно или все;
  программа не даст назначить одно сочетание на два действия.
- **Инструкция** и **О программе** (папка данных, резервные копии, сброс настроек).
- Всё применяется сразу, без перезапуска.

### Инструкция
- При **первом запуске** - короткая экскурсия на 8 страниц: библиотека и папки, теги и значки,
  коллекции, умный поиск, оценки/заметки/просмотр, защита данных, настройки.
- Открыть снова - **F1** или «⚙ Настройки → Инструкция».

### Программа запоминает
- Размер и положение окна, ширину панелей, сетку/список, сортировку, размер обложек,
  последний раздел и режим И/ИЛИ.

## v1.1 - стабильность, защита, интерфейс

### Защита от зависаний («добавил весь диск C - всё встало»)
- **Нельзя добавить** весь системный диск, Windows, Program Files, ProgramData, AppData и папку
  самой программы - программа объяснит почему и что добавить вместо этого.
- **Предупреждение** для корня другого диска и всей папки пользователя.
- При обходе **пропускаются** служебные папки: Windows, Program Files, AppData, корзина,
  node_modules, .git, __pycache__, скрытые и системные папки, «ссылки-папки» (junction) -
  по ним обход мог бы уйти по кругу.
- **Добавление идёт в фоне**: окно не зависает, видно сколько найдено, есть кнопка «Остановить».
  На 50 000 файлов программа спросит, точно ли продолжать. Остановил - выбираешь:
  оставить уже добавленное или убрать всё.
- **Безопасный режим**: если прошлый запуск завис (или программу закрыли через диспетчер
  задач), при запуске предложит запуститься без проверки файлов и откроет «Папки библиотеки».
  Чистить папку программы в AppData больше не нужно. Вручную: `python main.py --safe`.
- Если в библиотеке **уже лежит** весь диск или системная папка (с прошлых версий),
  при запуске программа предложит её убрать.

### Быстрее
- База в режиме WAL и запись пачками: 20 000 файлов добавляются меньше чем за секунду.
- Сетка показывает **по 1000 файлов**, дальше - кнопка «Показать ещё». Тысячи обложек
  больше не строятся разом.
- Память на отмену (Ctrl+Z) ограничена ~300 МБ при любой величине библиотеки.
- Слежение за папками обновляет только изменения; большие библиотеки полностью
  перепроверяются реже (15-30 минут вместо 5).

### Удобнее
- **Папки в сайдбаре** (раздел «ПАПКИ»): клик - файлы этой папки; ПКМ - показать в Проводнике,
  проверить, **убрать папку из библиотеки** (с её файлами или без). ПКМ по заголовку - добавить папку.
- **Назад / Вперёд** между разделами: кнопки ◀ ▶ и Alt+← / Alt+→.
- **Обложки PDF** - первая страница документа.
- **Тема**: тёмная в стиле Steam (по умолчанию), светлая или как в системе -
  «☰ Ещё → 🎨 Тема».
- Сайдбар шире - длинные названия больше не обрезаются.

## v1.0 - большой выпуск

### Значки тегов
- В правом нижнем углу обложки - **значки тегов: до 3**, остальные свёрнуты в **«…»**.
  Первым идёт тип файла (🖼 у картинок, 🎬 у видео, 📄 у документов…), дальше твои теги.
- Значок - кружок цвета тега, в нём символ или **своя картинка**. Свои теги по умолчанию -
  первая буква названия.
- Настроить: ПКМ по плашке → «🖼 Цвет и значок…» или «🗂 Теги → 🖼 Значок…».
  Цвет, любой символ/эмодзи (есть набор из 33 готовых), своя картинка любого размера -
  программа сама уменьшит её и сохранит в папке программы. «↺ По умолчанию» - вернуть как было.
- Значки видны и на плашках фильтра, и на тегах файла справа, и в окне «Метки».

### Оценки, заметки, быстрый просмотр
- **Оценка 1-5 ★**: звёзды справа, клавиши 1-5 (0 - снять), колонка в списке, звёзды на обложке,
  сортировка «По оценке», поиск `оценка>=4`.
- **Заметка к файлу** справа; сохраняется сама; ищется поиском (`заметка:текст` или просто словом).
- **Быстрый просмотр - Пробел** (как Quick Look): картинки, анимированные GIF, текст и код,
  PDF, видео и музыка. ← → листать, 1-5 оценка, Enter открыть, Пробел/Esc закрыть.

### Удобство
- **Ctrl+Z / Ctrl+Y - отмена и повтор ЛЮБОГО действия**: теги, коллекции, оценки, заметки,
  слияния, удаление из библиотеки, переименование файлов (имена на диске тоже вернутся).
  Кнопки ↶ ↷ слева на панели показывают, что именно отменится.
- **Горячие клавиши** - F1 показывает все: Пробел, Enter, F2, Del, Ctrl+D, Ctrl+E, 0-5, F5,
  Ctrl+1/2, Ctrl+I, Esc… Клавиши без Ctrl работают только в списке файлов - печатать в поиске
  и заметке они не мешают.
- **Автодополнение тегов в поиске**: пишешь `#ко` - предлагает `#Кошки` (и с минусом: `-#ко`).
- **История поиска** - в меню «?» (последние 10 запросов, которые что-то нашли).

### Умные функции
- **Поиск картинок по цвету** - кнопка 🎨 рядом с поиском или `цвет:синий`. Цвета картинок
  считаются сами в фоне (12 понятных цветов).
- **🕘 Недавние** в сайдбаре - что открывал из программы, последние сверху.
- **📊 Статистика** (Ctrl+I): сколько файлов и места, типы файлов, популярные теги,
  добавления по месяцам, самые большие файлы, дубликаты.
- **✏ Пакетное переименование** (F2): шаблон `{имя} {n} {дата} {папка} {тег}`, счётчик,
  «найти → заменить», регистр; предпросмотр «было → станет», проверка запрещённых символов
  и совпадений имён; теги и оценки остаются; Ctrl+Z возвращает старые имена.
- Экспорт/импорт теперь переносит и оценки, заметки, символы значков.

## v0.9 - дубликаты
- **⧉ Дубликаты** в сайдбаре (появляется, только когда они есть): файлы с одинаковым
  **содержимым** - имя не важно. Копии стоят в сетке рядом.
- Ищутся сами в фоне после каждой проверки файлов; вручную - «☰ Ещё → ⧉ Найти дубликаты»
  (итог: сколько групп, лишних копий и места они занимают).
- Как сравнивается - три сита: размер → начало и конец файла → всё содержимое (BLAKE2b).
  Целиком читаются только файлы, совпавшие по первым двум; отпечатки запоминаются и
  пересчитываются, только если файл изменился. Пустые файлы не считаются.
- Справа у файла с копиями - список копий и кнопки:
  **Объединить теги копий** · **Оставить в библиотеке только эту** (с диска ничего не удаляется) ·
  **🗑 Остальные копии - в Корзину…** (с подтверждением и списком; вернуть можно из Корзины;
  теги копий переходят к оставшемуся файлу; перед этим - резервная копия базы).
- Поиск: `дубликат` (или `-дубликат`).
- **Убранные из библиотеки файлы больше не возвращаются** при проверке папок.
  Передумал - «Папки библиотеки → ↩ Вернуть убранные файлы».

## v0.8 - вложенные теги
- Тег можно вложить в другой: «Кошки» внутри «Животные», «Персидские» внутри «Кошки» - глубина любая.
- Фильтр, поиск `#Животные`, исключение `-#Животные` и динамические коллекции по родителю
  находят и файлы со всеми вложенными тегами. Счётчики на плашках это учитывают.
- **Менеджер тегов** показывает дерево (вложенные - с отступом под родителем), колонку «Входит в»,
  кнопки «＋ Вложенный тег…» и «↳ Вложить в…» (двойной клик по «Входит в» - то же самое).
- **ПКМ по плашке** в фильтре: «↳ Вложить в другой тег…», «＋ Вложенный тег…».
- Подсказки на плашках и в окне «Метки» показывают полный путь: «Животные › Кошки».
- **Папки → теги** повторяет вложенность папок: Школа/Математика → тег Математика внутри Школа.
- Защита: тег нельзя вложить сам в себя или в своего потомка. Удалил тег из середины -
  его вложенные поднимаются на уровень выше; слил теги - вложенные переезжают в итоговый.
- Экспорт/импорт сохраняет вложенность.

## v0.7 - лучше конкурентов (разбор: docs в проекте, «конкуренты-и-план»)
- **Умный поиск.** Пишешь как удобно: `кот`, `#Школа`, `-#Черновик`, `.pdf`, `размер>10мб`,
  `добавлен:7д`, `изменён:30д`, `путь:Учёба`, `★`, `кот | пёс`. Под строкой видно,
  как программа поняла запрос. Кнопка «?» вставляет примеры, «💾» сохраняет поиск
  как динамическую коллекцию.
- **Правила авто-тегов** (☰ Ещё): «лежит в папке Школа → тег Школа», «имя скриншот* → Скриншоты»,
  по расширению, по части пути. Новые файлы получают теги сами, видно сколько файлов подходит.
- **Папки → теги** (☰ Ещё): отметь свои папки - каждая станет тегом с правилом. Структура,
  которую ты уже построил, превращается в теги за один клик, файлы не двигаются.
- **Потерянный файл: «🔎 Найти, куда делся…»** - ищет в фоне похожие файлы (то же имя,
  тот же размер, похожее имя) в папках библиотеки, рядом со старым местом, на Рабочем столе,
  в Загрузках и Документах; показывает варианты с причиной, выбираешь - теги переезжают.
- **Резервные копии** (☰ Ещё): сами раз в день и перед опасными действиями, последние 15,
  восстановление в два клика (текущее состояние тоже сохраняется копией).
- **Экспорт/импорт тегов** в открытый JSON - данные не заперты в программе; импорт находит
  файлы по пути, а на другом компьютере - по имени и размеру.
- **Ничего рядом с твоими файлами:** база, обложки и копии - в папке программы.
- **Понятные пустые экраны:** пустая библиотека - большая кнопка «Добавить папку»;
  «ничего не найдено» - кнопка «Сбросить поиск и теги»; пустая коллекция - подсказка, что делать.
- **Тулбар проще:** каждый день - на виду, редкое - в «☰ Ещё».
- **Быстрее на больших библиотеках:** готовые обложки кэшируются, клик по тегу не
  перерисовывает тысячи картинок.
